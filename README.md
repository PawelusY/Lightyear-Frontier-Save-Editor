# Lightyear-Frontier-Save-Editor

ENG:

This is an unofficial save editor for Lightyear Frontier, designed to transfer player progress. If you joined your world and got the intro again, have none of your items, but everything else loaded correctly and your buildings are still there, then you know you need to use this tool

## What do you need?

> [!IMPORTANT]
> - Python 3.10 or newer
> -  A positive attitude
> -  Be patient because it is worth fighting for your progress!!

_I know it looks like complicated, but it's just everything explained in more detail so you know the most important things._

## Features
- Transferring items, mech components, and tools from one player to another if, after launching the game on Steam or another platform, a new player is created instead of your existing character being loaded.
-  Opening .sav save files.
-  Information about what is contained in a player's inventory, mech, and tools.
-  Comparing the number of occurrences of IDs between save files.
-  Replacing an ID and saving the result to a new file without overwriting the source file.
-  Creating auxiliary files during an ID replacement operation to allow it to be undone: a copy of the original save and verification metadata.
-  The Undo Transfer / Restore Original function, which restores the exact save from before the operation, provided that the auxiliary files have been preserved.
